# AGENTS.md

## Project purpose

**Growth Eng MCP** is a Model Context Protocol (MCP) server and agent skill suite for autonomous growth engineering. It operates on the `.growth-eng` knowledge base in a repository to ideate, plan, lint, and visualize product experiments.

## Context routing

- **Before changing project setup, tools, or documentation:** READ `README.md`.
- **When working on core MCP tools, prompts, or services:** CHECK `src/core/`.
- **When working on knowledge base services:** CHECK `src/core/services/`.
- **When ideating a new growth experiment (`/generate-experiment-idea`):** USE `.agents/skills/generate-experiment-idea/SKILL.md`.
- **When planning and speccing an experiment (`/plan-experiment`):** USE `.agents/skills/plan-experiment/SKILL.md`.
- **When building a hypothesis tree visualization (`/hypothesis-tree`):** USE `.agents/skills/hypothesis-tree/SKILL.md`.
